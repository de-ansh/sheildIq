# ShieldIQ frontend

React 19 + Vite + Tailwind. See the [project README](../README.md) for setup, tests and deployment.

```sh
pnpm dev      # http://localhost:5173, proxies /api to the backend on :5001 (API_PROXY_TARGET overrides)
pnpm test     # component tests
pnpm e2e      # browser tests (starts its own backend and frontend)
pnpm build    # production build in dist/
```
